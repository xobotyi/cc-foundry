# Import the ADR index into every session, one line per ADR

- **Date:** 2026-10-24
- **Governs:** `plugins/the-blueprint/skills/adr/assets/adr-index-template.md`,
  `plugins/the-blueprint/skills/adr/SKILL.md`

Agents decide against a recorded decision when they never open the ADR directory. The index is imported into the
project's CLAUDE.md so every session holds it, which makes every field in it a cost paid in every session; a line
carries the number, the title, and a link.

## Decision

- **Imported.** `design-docs/ADR.md` is imported into the project's CLAUDE.md.
- **The preamble carries the reading rules**: read an area's ADRs before changing its code, stop and ask on a conflict,
  and write ADRs through the `adr` skill. The rules reach sessions that never load the skill.
- **One line per ADR** — the number, the title, and a link from the repository root. `Governs`, `Revisit if`, and the
  pending line stay in the ADR.
- **Areas.** Lines group under the area of each ADR's first `Governs` path. Areas run alphabetically by path, lines by
  number.

## Why

- Agents decided differently from recorded decisions because they forgot to read the ADR directory (the user's
  observation on kartta, 2026-10-24).
- kartta's index, with `Governs` and `Revisit if` on every entry, measured 948 lines, about 20k tokens per session;
  title-only lines measured about 7.7k (2026-10-24).
- A relative `./adr/` link loses its base once the index is inlined into CLAUDE.md. A link from the repository root
  resolves there and on GitHub.

## Consequences

- Every added, deleted, or retitled ADR edits the index, so parallel branches conflict on it. Accepted.
- An agent scans an area's titles instead of matching its exact file against `Governs`. Accepted.

## Rejected

- **No index, with the directory as the index** — depends on agents remembering to look.
- **`Governs` and `Revisit if` on every line** — about 12k more tokens per session at kartta's size, and the copies
  drift from the ADRs.
- **Sections by status or by group number** — ADRs carry no status
  ([ADR 1.10](/design-docs/adr/1.10-decision-record-lifecycle.md)), and a group number does not locate code.

## Revisit if

The host loads an imported file only in sessions that touch its paths, or the index outgrows the instruction budget of
the CLAUDE.md that imports it. Confidence medium: the token figures were measured on one project.
