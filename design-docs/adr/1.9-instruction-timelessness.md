# Write instruction artifacts in the timeless present

- **Date:** 2026-08-28
- **Governs:** `plugins/*/skills/`, `plugins/*/output-styles/`, `plugins/*/agents/`, `plugins/*/hooks/`, `CLAUDE.md`

Instruction text is read for months by a model that treats it as fact, while the world it describes moves. No sentence
in an instruction artifact depends on when it is read, at the cost of revisiting each anchored claim when its anchor
moves.

## Decision

- **Admission.** A statement enters a persistent artifact only if changing it would change intended behavior. Volatile
  facts — dates, live versions, rosters, prices, repository state — come from runtime injection or retrieval. Content
  that cannot sit behind a prompt-cache breakpoint does not belong in the artifact.
- **Phrasing.** Rolling referents are banned: `currently`, `now`, `new`, `newer`, `latest`, `recent`, `soon`,
  `eventually`, `no longer`, `still`, `does not yet`, `as of this writing`, `at present`. A rolling word is admissible
  only beside a fixed anchor: a version range, a model set, or a date.
- **Domain time stays.** Durations, expiry, retry backoff, ordering, and migrations are part of what the subject does
  and stay verbatim. A plan keeps its modality and is never promoted to fact.
- **Scope.** The rule covers instruction context: SKILL.md, `references/`, CLAUDE.md, output styles, agent definitions,
  hook prompts, and ADR text. Commit messages, GitHub release notes, the History lines and dated figures of ADRs, and
  the dated research syntheses in `docs/` are exempt.

## Why

- A model does not discount an old document the way a person does: instruction hierarchy places the text above its own
  knowledge, so a stale instruction is obeyed, not ignored. Evidence and prior art — Google's named rule, Grafana's
  `Grafana.Timeless` lint rule, ElevenLabs' skill library: [`docs/timeless-present.md`](/docs/timeless-present.md).
- An audit found 38 rolling model referents in `plugins/ai-helpers` (2026-08-28).
- Tense has no measured effect on instruction-following. The payoff is durability, and durability alone justifies the
  rule.

## Consequences

- An anchored claim needs revisiting when its anchor moves. A stale anchored claim reads as stale, while a stale rolling
  claim reads as current. Accepted.
- Compliance is greppable against the fixed word list.
- Timeless is not immutable: soft defaults calibrated against one model generation need re-examining when it moves.

## Rejected

- **Deleting temporal words** — destroys domain time.
- **Timelessness as a compliance technique** — tense has no measured effect on instruction-following.

## Revisit if

Evidence shows models discount stale in-context instructions the way people discount old documents. Confidence not
recorded.
