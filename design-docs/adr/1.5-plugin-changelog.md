# Ship one GitHub release per plugin version bump as its changelog

- **Date:** 2026-07-10
- **Governs:** `.claude/skills/release/`, `plugins/*/.claude-plugin/plugin.json`

Plugins version independently, and installers need to see what changed between versions. Every bump that lands on master
gets a GitHub release whose notes are the changelog, with no CHANGELOG.md files, at the cost of a tag per plugin
version.

## Decision

- **One release per bump**, created after the bump lands on master: tag `<plugin>-v<X.Y.Z>`, title `<plugin> v<X.Y.Z>`,
  targeting the commit that landed the bump. `gh release create` makes the tag; nobody tags by hand.
- **The notes are the changelog** — written for installers, segmented by changed component, distilled from commits and
  never a commit list. No CHANGELOG.md file exists in the repository.
- **Push authorization covers release creation.** A pushed bump without a release is an incomplete ship.
- **No backfill.** A plugin's first release rides its next version bump.
- The workflow lives in the `release` project skill.

## Why

- Shipping ended at `git push` — no tags, no releases, no changelog — so a marketplace user read commit history to learn
  what changed between versions (2026-07-10).

## Consequences

- Plugins accumulate one tag per version; compare links exist from a plugin's second release onward.
- A missing release is detectable: a `plugin.json` version ahead of the plugin's latest `<plugin>-v*` tag.
- Note quality depends on commit discipline; the git-commit skill's commit bodies are the source material.
- Release creation needs an authenticated `gh`; a session without one reports the gap instead of skipping the release.

## Rejected

- **Per-plugin CHANGELOG.md files** — duplicate the release notes, drift, and the plugin install flow does not show
  them.
- **Tagless releases** — do not exist; GitHub creates the tag at publish time.
- **Backfilled releases for the versions current at adoption** — a page of thin same-day "initial" releases with no
  changelog value.

## Revisit if

The plugin install flow starts showing a changelog file, or the marketplace offers its own version notes. Confidence not
recorded.
