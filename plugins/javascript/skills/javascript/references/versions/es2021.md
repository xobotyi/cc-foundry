# ECMAScript 2021

12th edition, ratified June 2021. A small edition: three assignment operators, numeric separators, one string method,
one promise combinator, and the weak-reference primitives.

## Syntax

- **Logical assignment** — `a ??= b` assigns when `a` is nullish, `a ||= b` when falsy, `a &&= b` when truthy. All three
  short-circuit: the right side is not evaluated and no assignment happens when the test fails, so a setter does not
  fire.
- **Numeric separators** — `1_000_000`, `0xFF_FF`, `1_000n`

## Built-ins

- **`String.prototype.replaceAll`**
- **`Promise.any`** and **`AggregateError`**
- **`WeakRef` and `FinalizationRegistry`** — non-owning references and post-collection callbacks

## Traps

- **`replaceAll` throws `TypeError` on a non-global regular expression.** Passing `/x/` is a `TypeError`; `/x/g` works,
  but then `replace` would have done the same job.
- **`||=` fires on `0` and `""`.** For a numeric or string option, `??=` is almost always the intended operator.
- **`Promise.any` rejects with `AggregateError`, not the last error.** The individual failures are on `err.errors`.
- **Never reach for `FinalizationRegistry` to release a resource.** The callback is not guaranteed to run. Use `using`
  or an explicit close in `finally`.
