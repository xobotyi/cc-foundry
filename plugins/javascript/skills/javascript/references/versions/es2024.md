# ECMAScript 2024

15th edition, ratified June 2024. Adds grouping, the promise-capability constructor replacement, and the `v` regular
expression flag.

## Built-ins

- **`Object.groupBy(items, cb)` and `Map.groupBy(items, cb)`**
- **`Promise.withResolvers()`** — returns `{ promise, resolve, reject }`
- **`String.prototype.isWellFormed` and `toWellFormed`** — detect and repair lone surrogates
- **Resizable `ArrayBuffer`** — `new ArrayBuffer(n, { maxByteLength })` plus `resize()`; `SharedArrayBuffer` gets
  `grow()`.
- **`ArrayBuffer.prototype.transfer` and `transferToFixedLength`** — move ownership of the backing store and detach the
  original.
- **`Atomics.waitAsync`** — non-blocking wait, usable on the main thread.

## Regular expressions

- **`v` flag (`unicodeSets`)** — a stricter superset of `u`, adding set difference `[[a-z]--[aeiou]]`, set intersection,
  nested classes, string literals in classes `[\q{ab|cd}]`, and properties of strings such as `\p{RGI_Emoji}`.

## Traps

- **`Object.groupBy` returns a null-prototype object.** `result.hasOwnProperty` is `undefined` and
  `"toString" in result` is `false`. Read keys with `Object.hasOwn` or bracket access, and never assume inherited
  `Object.prototype` methods.
- **`Map.groupBy` compares keys with SameValueZero**, so `NaN` groups together and `-0` collapses into `0`.
  `Object.groupBy` stringifies the key instead, so `1` and `"1"` become one group.
- **`v` requires escaping characters that `u` allows raw.** `( ) [ ] { } / - \ |` must be escaped inside a class:
  `new RegExp("[a{]", "v")` is a `SyntaxError` while the `u` form is accepted. Switching a pattern from `u` to `v` is
  not mechanical.
- **Properties of strings only exist under `v`.** `/\p{RGI_Emoji}/u` throws `SyntaxError`; the `v` form works.
- **`transfer()` detaches the source buffer silently.** The original reports `byteLength` 0, and indexed reads through
  an existing typed-array view return `undefined` instead of throwing — the failure surfaces far from its cause.
