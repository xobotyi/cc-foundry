# ECMAScript 2020

11th edition, ratified June 2020. Adds the two operators that replace most defensive-access boilerplate, a second
numeric type, and the module-loading primitives.

## Syntax

- **Optional chaining `?.`** — `a?.b`, `a?.[k]`, `f?.()`. Short-circuits the whole chain on `null` or `undefined`, so
  `a?.b.c` does not throw when `a` is nullish, but does throw when `a.b` is nullish.
- **Nullish coalescing `??`** — falls back only on `null` and `undefined`, unlike `||` which falls back on `0`, `""`,
  `NaN`, and `false`.
- **`import()`** — dynamic import returning a promise for the module namespace object.
- **`import.meta`** — host-populated object; `import.meta.url` is the module's URL.
- **`export * as ns from "mod"`** — namespace re-export.

## Built-ins

- **`BigInt`** — arbitrary-precision integer primitive with the `123n` literal form.
- **`globalThis`** — the global object under every host.
- **`Promise.allSettled`** — never rejects; resolves an array of `{ status, value }` or `{ status, reason }`.
- **`String.prototype.matchAll`** — iterator of full match objects.

## Behavior changes

- **`for...in` enumeration order is specified** for the common case: integer-like keys ascending, then string keys in
  insertion order, then symbols. Previously implementation-defined.

## Traps

- **`??` cannot be mixed with `||` or `&&` without parentheses.** `a || b ?? c` is a `SyntaxError`. This is deliberate:
  the precedence would otherwise be ambiguous to a reader.
- **`?.` suppresses only the access, not the rest of the expression.** `obj?.method()` throws `TypeError` when `obj`
  exists and `method` does not. Write `obj?.method?.()` when both are optional.
- **Overusing `?.` hides missing data.** A field that must be present should throw at the access, not silently yield
  `undefined` three layers downstream.
- **BigInt does not mix with Number in arithmetic.** `1n + 1` throws `TypeError`. Comparison does mix: `1n == 1` is
  `true`, `1n < 2` is `true`.
- **`JSON.stringify` throws `TypeError` on a BigInt.** Convert with `String(v)` or install a `toJSON` method.
- **`Promise.allSettled` results are not the values.** Each element is a wrapper object; reading `.value` on a rejected
  entry yields `undefined` rather than throwing.
