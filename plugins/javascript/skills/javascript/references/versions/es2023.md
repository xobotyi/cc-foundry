# ECMAScript 2023

14th edition, ratified June 2023. Adds the non-mutating array methods, which remove the `[...arr].sort()` copy idiom.

## Built-ins

- **Change array by copy** — `toSorted()`, `toReversed()`, `toSpliced(start, count, ...items)`, and
  `with(index, value)`. Each returns a new array and leaves the receiver untouched. `TypedArray` gets `toSorted`,
  `toReversed`, and `with`.
- **`findLast` and `findLastIndex`** on `Array` and `TypedArray` — search from the end.
- **Symbols as WeakMap keys** — a registered symbol is still rejected; only unique symbols are permitted.

## Syntax

- **Hashbang grammar** — a leading `#!` line is a comment in a script or module. It only has meaning as the first two
  characters of the file.

## Traps

- **`toSorted()` still needs a comparator for numbers.** It fixes mutation, not the default lexicographic ordering:
  `[10, 9, 1].toSorted()` is `[1, 10, 9]`.
- **`with()` on an out-of-range index throws `RangeError`**, where `arr[i] = v` would have grown the array or added a
  string-keyed property.
- **The copying methods materialize holes.** `[1, , 3].toSorted()` returns a dense `[1, 3, undefined]`, the `undefined`
  sorting last, while `[1, , 3].sort()` keeps a hole at index 2.
