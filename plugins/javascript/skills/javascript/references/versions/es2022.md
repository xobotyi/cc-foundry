# ECMAScript 2022

13th edition, ratified June 2022. The edition that finished the class syntax and made modules asynchronous. Everything
here except top-level `await` is Baseline widely available, so the rest is the practical syntax floor for a project with
no legacy browser target.

## Syntax

- **Class fields** — public instance fields (`x = 1`), static fields (`static x = 1`), private instance and static
  fields (`#x = 1`), private methods and private accessors (`#m() {}`, `get #v() {}`).
- **Ergonomic brand checks** — `#x in obj` tests private-field presence without throwing.
- **Class static initialization blocks** — `static { ... }` runs once at class definition with `this` bound to the
  class, for setup a field initializer cannot express.
- **Top-level `await`** — permitted at the top level of a module, never in a script or a CommonJS file.

## Built-ins

- **`Object.hasOwn(obj, key)`**
- **`.at(index)`** on `Array`, `String`, and `TypedArray` — negative indices count from the end
- **`Error` `cause`** — `new Error(msg, { cause: err })` and `err.cause`
- **RegExp `d` flag** — match indices on `result.indices`

## Traps

- **A derived-class field is unassigned while the base constructor runs.** The base constructor completes before any
  derived field initializer executes, so an overridable method the base calls reads `undefined` from every derived
  field.
- **An arrow-function field is an own property, a method is on the prototype.** `class F { m() {} n = () => {} }` gives
  every instance its own `n` and shares one `m`. The arrow binds `this` and costs one closure per instance; the method
  does neither.
- **A field initializer runs in declaration order and can read `this`.** Reading a field declared later yields
  `undefined` with no error.
- **Private fields are not privacy from the debugger, they are hard encapsulation from code.** Accessing `#x` on an
  object that does not have it is a `TypeError`, not `undefined` — which is what makes `#x in obj` necessary.
- **Top-level `await` breaks under a diamond dependency in Safari 15 through 26.** Two modules importing one module that
  uses top-level `await` hit WebKit bug 242740, and MDN records the implementation as partial across that whole range.
  WebKit's rewritten module loader targets Safari 27, so an engine baseline including Safari 26 cannot rely on top-level
  `await`.
- **Top-level `await` in an entry module delays every importer.** It is module-level blocking, not function-level — a
  slow fetch there stalls the whole graph below it.
