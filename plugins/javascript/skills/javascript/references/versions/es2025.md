# ECMAScript 2025

16th edition, ratified June 2025. The largest recent edition: lazy iterator pipelines, set algebra, and the module
attribute syntax.

## Built-ins

- **Sync iterator helpers** — `Iterator.prototype.map`, `filter`, `take`, `drop`, `flatMap`, `reduce`, `toArray`,
  `forEach`, `some`, `every`, `find`, plus `Iterator.from`. They are lazy: `g().map(f).take(3).toArray()` calls `f`
  three times regardless of how long `g` would run.
- **New `Set` methods** — `union`, `intersection`, `difference`, `symmetricDifference`, `isSubsetOf`, `isSupersetOf`,
  `isDisjointFrom`.
- **`Promise.try(fn)`** — runs `fn` immediately and captures a synchronous throw as a rejection, so a mixed sync/async
  function has one failure channel.
- **`RegExp.escape(str)`** — escapes a string for literal use inside a pattern.
- **`Float16Array` and `Math.f16round`** — half-precision storage and rounding.

## Syntax

- **Import attributes** — `import data from "./d.json" with { type: "json" }`, and the dynamic form
  `import("./d.json", { with: { type: "json" } })`.
- **JSON modules** — a JSON module exposes only a default export. The `with { type: "json" }` attribute is mandatory,
  not advisory; the module is rejected without it.
- **RegExp modifiers** — `(?i:...)`, `(?m:...)`, `(?s:...)` and the disabling forms `(?-i:...)` scope a flag to part of
  a pattern.
- **Duplicate named capture groups** — the same group name may appear in alternatives that cannot both match:
  `/(?<v>a)|(?<v>b)/`.

## Traps

- **An iterator helper consumes its source.** `it.map(f)` returns a new helper object, but both draw from the same
  underlying iterator; after the helper is drained the source is exhausted. Calling `toArray()` twice on the same chain
  gives the full result and then `[]`.
- **`Set` methods take any set-like, not only a `Set`.** The argument needs `size`, `has`, and `keys`; a plain `Array`
  throws `TypeError`. Wrap it: `a.union(new Set(b))`.
- **`Set` methods return a plain `Set`, never a subclass.** A `Set` subclass loses its identity across `union`.
- **`import.meta` and import attributes do not make a JSON module writable.** The default export is a live reference to
  one parsed object shared by every importer; mutating it mutates it for all of them.
- **`RegExp.escape` output is not readable.** It escapes leading identifier characters as hex, so `RegExp.escape("a.b")`
  is `"\\x61\\.b"`. Never build a pattern string for display with it.
- **A regular-expression modifier is not a flag.** `(?i:...)` affects only its group; the outer pattern keeps the flags
  on the literal.
